# Tienda en Línea

Sistema desarrollado en PHP bajo el patrón MVC.

## Tecnologías
- PHP
- MySQL
- CSS
- JavaScript

## Instalación
1. Clonar repositorio
2. En el repositorio deberia estar esta organización solo que se subio separado al no dejarme subir assets(OJO NO HAY PROBLEMA CON ESO)
```txt
tienda-online/
├── assets/
│   ├── admin/
│   ├── css/
│   ├── js/
│   ├── imágenes/
│   └── proveedor/
├── modelos/
├── views/
├── controladores/
└── index.php
```
3. Importar base de datos
4. Configurar conexión en config
5. Ejecutar en XAMPP
