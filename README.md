# Tienda en Línea

Sistema desarrollado en PHP bajo el patrón MVC.

## Tecnologías
- PHP
- MySQL
- CSS
- JavaScript

## Instalación
1. Clonar repositorio
2. En el repositorio deberia estar esta organización solo que se subio separado al no dejarme subir assets(OJO NO HAY PROBLEMA CON ESO)
Tienda-online
 assets/
 ├── admin/
 ├── css/
 ├── js/
 ├── images/
 └── vendor/
models/
views/
controllers/
index.php

4. Importar base de datos
5. Configurar conexión en config
6. Ejecutar en XAMPP
